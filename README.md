# HTML & CSS Task Collection

This workspace contains 8 static HTML/CSS website projects created as part of a front-end task set.

## Quick start

- Open [index.html](index.html) in the root folder to access a landing page with links to all 8 projects.
- Click any card on the landing page to open the corresponding website in a new tab.
- You can also open individual project folders directly if you want to view a single site.

## Project folders

1. [01.Luxterior/index.html](01.Luxterior/index.html) - non-responsive website
2. [02.MEBELEVV/index.html](02.MEBELEVV/index.html) - non-responsive website
3. [03.ChiFlow/index.html](03.ChiFlow/index.html) - non-responsive website
4. [04.Authrntik/index.html](04.Authrntik/index.html) - non-responsive website
5. [05.LifeStyle/index.html](05.LifeStyle/index.html) - responsive website
6. [06.CALISTO/index.html](06.CALISTO/index.html) - responsive website
7. [07.Erric/index.html](07.Erric/index.html) - responsive website
8. [08.Apple/index.html](08.Apple/index.html) - responsive website

## Overview

- Folders 01 through 04 contain sites built as static layouts without responsive behavior.
- Folders 05 through 08 contain sites designed to adapt to different screen sizes.

## Notes

- Each task folder is a standalone project.
- The root landing page provides easy navigation for all of them.
- The projects use plain HTML and Tailwind CSS for styling.
