# HTML & CSS Task Collection

This workspace contains 8 HTML/CSS website projects created as part of a front-end task set.

## Project folders

1. `01.Luxterior/` - non-responsive website
2. `02.MEBELEVV/` - non-responsive website
3. `03.ChiFlow/` - non-responsive website
4. `04.Authrntik/` - non-responsive website
5. `05.LifeStyle/` - responsive website
6. `06.CALISTO/` - responsive website
7. `07.Erric/` - responsive website
8. `08.Apple/` - responsive website

## Overview

- Folders `01` through `04` contain sites built as static layouts without responsive behavior.
- Folders `05` through `08` contain sites designed to adapt to different screen sizes.

## How to use

- Open any folder and launch its `index.html` file in a web browser.
- For the responsive sites (`05` to `08`), resize the browser window to see the layout adjust.

## Notes

- Each task folder is a standalone project.
- The root folder does not contain a shared stylesheet or build setup.
